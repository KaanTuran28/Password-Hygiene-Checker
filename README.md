## English

A CLI that checks password strength and breach exposure — without ever exposing the password itself.

🔒 **Your password is never sent anywhere in full.** Only a 5-character SHA-1 prefix is sent to the [Have I Been Pwned API](https://haveibeenpwned.com/API/v3#PwnedPasswords) (the k-anonymity model). Nothing is written to disk except the strength verdict and breach count — the password itself is never logged or saved.

### Overview

- **Local strength check**: length, character-class diversity, common-password-list match, estimated entropy.
- **Breach check**: queries Have I Been Pwned's Pwned Passwords API using k-anonymity — your password (or its full hash) never leaves your machine.
- Works fully offline too (`--skip-pwned-check`), and degrades gracefully if the API is unreachable.

### Installation

```bash
pip install -r requirements.txt
```

Or install it as a CLI command:

```bash
pip install -e .
password-hygiene-checker --password "your-password-here"
```

### Usage

```bash
# Prompted securely (recommended — nothing appears in your shell history)
python password_hygiene_checker.py

# Or pass it inline (visible in shell history — avoid for real passwords)
python password_hygiene_checker.py --password "your-password-here"

# Local strength check only, no network call
python password_hygiene_checker.py --skip-pwned-check

# Choose the report path
python password_hygiene_checker.py --output report.md

# Machine-readable output
python password_hygiene_checker.py --format json --output report.json

# CI/account-creation gating: exit 1 on a weak or breached password
python password_hygiene_checker.py --password "..." --fail-on-weak --fail-on-pwned
```

### CI Integration

`--fail-on-weak` and `--fail-on-pwned` turn a check into a gate — e.g. in an account-creation or password-reset flow that rejects weak/breached passwords before they're accepted:

```yaml
# GitHub Actions step (or any pipeline that provisions a default/service-account password)
- name: Reject weak or breached password
  run: password-hygiene-checker --password "$NEW_PASSWORD" --fail-on-weak --fail-on-pwned
```

Neither flag is required for plain report generation — the exit code stays `0` unless you opt in.

### How k-anonymity works

1. The password is hashed locally with SHA-1.
2. Only the **first 5 characters** of that hash are sent to the HIBP API.
3. HIBP returns every known breached hash suffix that shares that 5-character prefix (typically several hundred).
4. The match against the full hash happens **locally** — HIBP never sees the full hash or the password.

## Türkçe

Parola gücünü ve ihlal (breach) maruziyetini kontrol eden — ve bunu yaparken parolanın kendisini asla ifşa etmeyen bir CLI.

🔒 **Parolanız hiçbir zaman tam haliyle hiçbir yere gönderilmez.** Yalnızca 5 karakterlik bir SHA-1 öneki (k-anonimlik modeli kullanılarak) [Have I Been Pwned API](https://haveibeenpwned.com/API/v3#PwnedPasswords)'sine gönderilir. Güçlülük sonucu ve ihlal sayısı dışında hiçbir şey diske yazılmaz — parolanın kendisi asla loglanmaz veya kaydedilmez.

### Genel Bakış

- **Yerel güçlülük kontrolü**: uzunluk, karakter sınıfı çeşitliliği, yaygın parola listesiyle eşleşme, tahmini entropi.
- **İhlal kontrolü**: Have I Been Pwned'in Pwned Passwords API'sini k-anonimlik kullanarak sorgular — parolanız (veya tam hash'i) asla makinenizden çıkmaz.
- Tamamen çevrimdışı da çalışır (`--skip-pwned-check`) ve API'ye ulaşılamazsa zarif bir şekilde geriler (degrade olur).

### Kurulum

```bash
pip install -r requirements.txt
```

Veya bir CLI komutu olarak kurun:

```bash
pip install -e .
password-hygiene-checker --password "your-password-here"
```

### Kullanım

```bash
# Güvenli şekilde sorulur (önerilen — shell geçmişinizde hiçbir şey görünmez)
python password_hygiene_checker.py

# Veya satır içinde geçirin (shell geçmişinde görünür — gerçek parolalar için kaçının)
python password_hygiene_checker.py --password "your-password-here"

# CI/hesap oluşturma kapısı: zayıf veya ihlal edilmiş bir parolada çıkış kodu 1
python password_hygiene_checker.py --password "..." --fail-on-weak --fail-on-pwned
```

### CI Entegrasyonu

`--fail-on-weak` ve `--fail-on-pwned`, bir kontrolü bir kapıya (gate) dönüştürür — örn. zayıf/ihlal edilmiş parolaları kabul edilmeden önce reddeden bir hesap oluşturma veya parola sıfırlama akışında:

```yaml
# GitHub Actions adımı (veya varsayılan/servis hesabı parolası oluşturan herhangi bir pipeline)
- name: Reject weak or breached password
  run: password-hygiene-checker --password "$NEW_PASSWORD" --fail-on-weak --fail-on-pwned
```

Düz rapor oluşturma için hiçbir flag zorunlu değildir — siz açıkça belirtmediğiniz sürece çıkış kodu `0` olarak kalır.

### K-anonimlik nasıl çalışır

1. Parola yerel olarak SHA-1 ile hash'lenir.
2. Bu hash'in yalnızca **ilk 5 karakteri** HIBP API'sine gönderilir.
3. HIBP, bu 5 karakterlik önekle eşleşen bilinen tüm ihlal edilmiş hash son eklerini döndürür (genellikle birkaç yüz tane).
4. Tam hash ile eşleştirme **yerel olarak** gerçekleşir — HIBP asla tam hash'i veya parolayı görmez.
